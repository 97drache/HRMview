# HRM 아이콘 (발표·브랜드용)

`npm run icons` 로 재생성할 수 있습니다.

## 디자인

| | Desktop | Mobile |
|---|---------|--------|
| 색상 | 틸 (`#0d9488`) | 브랜드 녹색 (`#006b00`) |
| 모서리 | 약간 각진 squircle (rx 96) | 더 둥근 squircle (rx 118) |
| 테두리 | 이중 링 | 단일 링 |
| 하단 장식 | 가로 라인 | 작은 점 |

공통: 상승 막대 차트 + **HRM** 로고타입

## 발표용 파일

| 파일 | 용도 |
|------|------|
| `hrm-desktop-2048.png` | 데스크톱 단독 (슬라이드 삽입) |
| `hrm-mobile-2048.png` | 모바일 단독 |
| `hrm-icons-pair-4096x2048.png` | 나란히 비교 (4096×2048) |
| `hrm-icon-desktop.svg` / `hrm-icon-mobile.svg` | 벡터 원본 (무한 확대) |

앱에 적용되는 산출물은 `build/icon.ico`, `public/*`, `headcount-web/public/*` 입니다.
